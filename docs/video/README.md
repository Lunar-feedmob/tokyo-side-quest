## 录制说明

- 定位、打卡、拍照结果都在“在线试玩”里演示：定位是模拟坐标，照片是固定样例，页面上都有标注，**不是 AI 对真实照片的评价**。正式库里没有写入任何演示打卡记录，录制结束时用“清空全部数据”删掉了录制用的访客数据。
- “发现附近”一段的设备位置是模拟的（谷中）。
- 片尾的网址和二维码指向当前的 sslip.io 地址，**换正式域名后需要重做片尾**。
